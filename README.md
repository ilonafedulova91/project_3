# project_3

Курсовой проект загружает данные о странах и самолетах из API Nominatim и OpenSky,
сохраняет их в PostgreSQL и предоставляет аналитические запросы через класс `DBManager`.

## Запуск

1. Создайте базу PostgreSQL.
2. Укажите переменные окружения:
   - `DB_HOST`
   - `DB_PORT`
   - `DB_NAME`
   - `DB_USER`
   - `DB_PASSWORD`
3. Установите зависимости через Poetry.
4. Запустите `python main.py`.

По умолчанию программа использует список из 10 стран, что соответствует критерию проверки.
